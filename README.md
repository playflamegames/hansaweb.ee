## 🚀 Kasutamisjuhend

### Arenduskeskkond:
```bash
# Projekti kloonimine
git clone [repository-url]
cd webapp

# Sõltuvuste installimine
npm install

# Projekti ehitamine
npm run build

# Arendusserveri käivitamine (PM2-ga)
pm2 start ecosystem.config.cjs

# Serveri testimine
curl http://localhost:3000
```
